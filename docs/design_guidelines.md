# IEC104 Tester 界面设计规范

> 版本：1.0（2026-11-08）· 适用范围：`webui/frontend/src` 全部页面与组件
> 配套：`webui/frontend/src/theme.ts`（token 唯一来源）、`webui/frontend/README.md`（工程约定）、
> `tests/e2e/specs/ui-*.spec.ts`（自动门禁）、`docs/user_guide.md`（用户视角说明）

本规范的目标不是"看起来像某个设计系统"，而是让 8 个页面在**同一种语义**下表达同一件事：
什么坏了、什么在跑、什么能点、点了会发生什么。规范由三部分拼成：

1. **组件模式**取自 PatternFly / Carbon（成熟运维与数据密集界面），
2. **领域规则**取自 ISA-101 与 NUREG-0700 中适用于"工程测试工具"的部分，
3. **落地载体**是本项目现有的 antd 6 token 与自动巡检门禁。

---

## 1. 定位与边界

本产品是**工程测试工具**（协议调试、点表注入、报文分析），不是控制室 HMI。据此裁剪：

| 采纳 | 不采纳 |
|---|---|
| 颜色有且只有一种语义；状态必须可读 | 全屏工艺流程图 / 大屏投屏布局 |
| 信息层级：概览 → 明细 → 原始报文 | ISA-101 的"灰底低饱和"强制风格 |
| 危险操作有边界与二次确认 | 报警泛滥（alarm flood）管理与操作员轮次 |
| 密集数据表、等宽数字、可比较 | 7×24 操作员情境意识（situation awareness）指标 |
| 空态/加载/错误态完备 | 固定分辨率大屏适配 |

**判断准则**：拿不准某条规则要不要遵守时，问"这条规则保护的是操作员的人身/设备安全，还是工程师的排查效率？"本工具只对后者负责。

## 3. 设计原则

1. **一色一义**：同一种状态在全系统同色；同一个颜色不承担第二种含义。
2. **不靠颜色单独传信息**：颜色是加速器，文字/图标是事实来源（WCAG 1.4.1）。
3. **密度优先于留白**：这是工程师长时间盯屏的工具，一屏信息量 > 呼吸感。
4. **危险有边界**：只有会改变真实设备状态或不可逆的操作才配红色与二次确认。
5. **状态永远完整**：任何数据面都必须能回答"加载中 / 没有数据 / 出错了怎么办"。

## 4. 颜色与语义

### 4.1 唯一来源

颜色**只能**来自 `src/theme.ts` 的 antd token，或 `global.css` 中 `html[data-theme]` 变量。
组件内禁止出现 `#hex`、`rgb()`（`tests/test_frontend_style_tokens.py` 静态失败）。

### 4.2 语义映射

| 语义 | 使用场景 | Light token | Dark token | 允许的 Tag 预设 |
|---|---|---|---|---|
| 正常 / 运行 / 已启用 | 连接已建立、模拟运行中、点启用 | `colorSuccess` | `colorSuccess` | `success` |
| 中性 / 停止 / 未启用 | 已停止、未选择、默认态 | 默认文字 | 默认文字 | `default` |
| 信息 / 选中 / 计数 | 当前选中项、条数、角色标识 | `colorInfo` | `colorInfo` | `blue` |
| 注意 / 可恢复异常 | 暂停、丢弃计数、配置待生效 | `colorWarning` | `colorWarning` | `warning` |
| 错误 / 不可用 | 请求失败、契约不匹配、连接断开 | `colorError` | `colorError` | `error` |
| 品牌 / 主操作 | 主按钮、菜单选中、链接 | `colorPrimary` | `colorPrimary` | — |

**禁止**：同一语义在不同页面用不同预设。当前代码里的 `orange`（日志 WARNING、历史 rx/tx、SBO 标记）
与 `warning` 并存，属于同一语义两种颜色，必须收敛到 `warning`。

**Tag 预设白名单**：`success` / `default` / `blue` / `warning` / `error`。
`gold`、`cyan`、`purple`、`green`、`magenta` 的预置前景色在浅/深底上仅 2.8~3.4:1，不得使用。

**明示例外**（需在代码注释写明理由）：
- 录制中指示器可用红色（REC 行业惯例），但**必须同时有"录制中"文字**，且不用于其他状态。

### 4.3 不允许只靠颜色

每个状态标签必须同时具备：颜色 + 文字（表格内可再加图标）。禁止"绿点=正常、红点=故障"而无文字。
趋势图/图表必须有图例或直接标注，不得用颜色区分两条无标签曲线。

### 4.4 对比度

| 对象 | 要求 | 门禁 |
|---|---|---|
| 正文（<18.66px 或 <24px 粗体） | ≥ 4.5:1 | `ui-contrast.spec.ts` |
| 大字（≥24px 或 ≥18.66px 粗体） | ≥ 3:1 | 同上 |
| 占位符、禁用文字（非豁免场景） | ≥ 3:1（禁用控件按 WCAG 豁免） | 同上 |
| 控件边框、图标、焦点环 | ≥ 3:1 | `ui-nontext-contrast.spec.ts` |

**套件维度（T89）**：三项页级门禁（`ui-audit` / `ui-contrast` / `ui-nontext-contrast`）
按 `E2E_KITS`（默认 `pf,carbon`）**逐套件各跑一遍**——默认套件 Carbon 必须有同等门禁，
否则用户实际看到的界面无人看护。判定口径两条原则（已落地在门禁里）：焦点可见性只对
**键盘焦点**判定（`:focus-visible` 不匹配 = 鼠标/程序化聚焦，WCAG 2.4.7 不适用）；
纯图标按钮的**边框/分隔线**不作判定（可识别性由图标承担，图标对比度单独判）；
1~2px 的「屏幕阅读器专用」盒子（`.cds--visually-hidden`）是**有意隐藏**，不算裁切。

新页面加入巡检矩阵后，`CONTRAST_REPORT=1` 生成的报告必须无 `<3:1` 项。

## 5. 点表

主站与子站共用 `components/PointsTable.tsx`，规范对它一次性生效。

### 5.1 密度

- 行高 32px（`size="small"`），表头 32px，单元格内边距 4px 8px。
- 基准字号 13px；辅助信息 12px；禁止在单元格内用 14px 以上。
- 默认列宽（可拖拽，会话内记忆）：IOA 100 / 类型 80 / 名称 360 / 组 70 / 启用 80 / 值 150 / 品质 220。

### 5.2 对齐

| 列类型 | 对齐 | 字体 |
|---|---|---|
| IOA、HEX、序号、COT 码 | 左对齐 | 等宽（`.mono`） |
| 数值（YC/YM/STEP 值） | **右对齐** | 等宽 + `font-variant-numeric: tabular-nums` |
| 名称、品质文本 | 左对齐 | 正文 |
| 状态标签 | 居中或左对齐（同列一致） | 正文 |

> 右对齐是为了让小数点成列，工程师扫一列数值时才能发现量级异常。

### 5.3 单位与小数位

- 有 `unit` 时显示为"值 + 单位"（如 `12.34 kV`），单位用小一号字、次要色。
- 小数位取点位定义的 `decimal_places`；缺省规则：`|v| ≥ 1000` → 1 位，`≥ 10` → 2 位，其余 3 位。
- **禁止**对所有浮点一律 `toFixed(3)`。
- 导出（CSV/YAML）保留原始精度，不做 UI 舍入。

### 5.4 品质位

品质位必须解码后呈现，禁止直接显示原始整数或未解释的英文缩写。

| 位 | 掩码 | 含义 | UI |
|---|---|---|---|
| IV | 0x80 | 无效 | 值显示 `--` + `无效` 标签（error） |
| NT | 0x40 | 非当前值 | `非当前` 标签（warning） |
| SB | 0x20 | 替代值 | `替代` 标签（warning） |
| BL | 0x10 | 封锁 | `封锁` 标签（default）+ 值置灰 |
| OV | 0x01 | 溢出（QDS） | `溢出` 标签（warning） |

- 无位 → 显示 `-` 或留空，不占视觉权重。
- 多个位同时置位 → 按 IV > NT > SB > BL > OV 顺序显示，最多 2 个标签，其余进 tooltip。
- tooltip 必须给出位名与原始字节：`0x50 · IV BL`。

> **已修复（2026-11-08，见附录 A.2）**：此前 `QualityFlag` 用 `IV=0x40 / NT=0x20`、
> `quality_mask()` 用 `OV=0x04`，与标准不符，注入"无效"品质后界面读回 `GOOD`。
> 现两处统一按上表并补上 `SB` 位，编解码、注入、`to_int()` 共用 `QualityFlag`。
> 界面侧仍只显示英文缩写，中文标签/颜色/tooltip 见附录 A.3 第 1 项。

### 5.5 陈旧与禁用

- **禁用**（`enabled=false`）：整行文字降为次要色，标签 `未启用`（default），值不参与趋势/命令。
- **陈旧**：点值的时标超过 `max(3× 上报周期, 30s)` 未更新 → 值后加 `陈旧` 标记（warning）并附最后更新时刻。
  （当前点表快照不含时标，见附录 A-2。）

### 5.6 值着色

- 允许：YX `ON` 用 `colorSuccess`、`OFF` 用默认色。
- 禁止：按数值大小映射红绿（会与告警色冲突）、整行背景着色。

## 6. 告警与事件

本工具的"告警"分三类，规则不同：

| 类别 | 载体 | 是否需确认 | 示例 |
|---|---|---|---|
| 系统异常 | 顶部横幅 `Alert` | 是（关闭即确认，会话内不再弹） | 契约版本不匹配、WS 断开、背压丢弃 |
| 运行事件 | 日志页 | 否（可过滤/导出） | 启停、命令收发、注入生效 |
| 协议异常 | 报文查看器 + 日志 ERROR | 否（定位用） | COT 异常、序号跳变、未知类型 |

### 6.1 严重度

四级，固定映射：`次要(info)` / `注意(warning)` / `错误(error)` / `致命(critical)`。
日志页的 `DEBUG/INFO/WARNING/ERROR/CRITICAL` 必须映射到上述四级，同一级别全系统同色
（当前 `CRITICAL` 用 `magenta`、`WARNING` 用 `orange`，需收敛，见附录 A-3）。

### 6.2 确认与抑制（范围界定）

- **确认（ack）**：仅对"系统异常横幅"生效。同一 `(类型, 关键参数)` 在一次会话内只弹一次。
- **抑制（shelve）**：本期不做。若后续引入，必须显示"已抑制 N 条"，且抑制有到期时间。
- 日志页的"暂停"不是抑制：暂停期间仍写入缓冲，恢复后补齐（已实现）。

### 6.3 排序与分组

- 默认按时间**倒序**（最新在上）；提供正序切换时必须在表头可见。
- 同毫秒多条按 `source → level` 稳定排序，避免刷新跳动。
- 分组只按 `source` 或 `级别`，不按自由文本。

### 6.4 横幅告警写法

`症状（发生了什么） + 影响（还能不能用） + 动作（点哪里）`，禁止只写错误码。
> 例：「WebSocket 已断开，实时点值暂停更新。正在自动重连（第 3 次）…」

## 7. IEC 104 语义 → UI

这一节是"协议正确"与"界面正确"的接缝，最容易被漏掉。

### 7.1 品质位

见 §5.4（含两套掩码不一致的现状说明）。报文查看器与历史页同样适用：只要出现 QDS/SIQ/DIQ，就必须解码。

### 7.2 传送原因（COT）

| COT | 名称 | UI 权重 |
|---|---|---|
| 3 | 自发 | 高（事件驱动，日志可高亮） |
| 1 | 周期 | 低（可折叠/降噪） |
| 5 | 请求 | 中 |
| 6 / 7 | 激活 / 激活确认 | 中（成对显示同一命令链路） |
| 8 / 9 | 停止激活 / 停止确认 | 中 |
| 10 | 激活终止 | 中（链路结束标记） |
| 20 / 21–36 | 站总召 / 组总召 | 中（显示组号） |
| 44 / 45 / 46 / 47 | 未知类型/COT/公共地址/IOA | **高 + error 色**（这是对端实现缺陷） |

显示格式：`名称(码)`，如 `自发(3)`。未知 COT 不得落到 `default`。

### 7.3 时标

| 场景 | 格式 | 说明 |
|---|---|---|
| 报文、日志（同一天内） | `HH:mm:ss.SSS` | 省列宽 |
| 报文、日志（跨 0 点） | `MM-DD HH:mm:ss.SSS` | 自动切换，不靠用户记忆 |
| 历史、导出、tooltip | `YYYY-MM-DD HH:mm:ss.SSS` | 本地时区 |
| 趋势 X 轴 | 时间轴（`type:'time'`），刻度自适应 | 不用"时分秒"字符串类目轴 |

- `formatDateTime` 不得依赖运行环境区域设置硬编码 `zh-CN`；应跟随 UI 语言。
- CP56Time2a 的 IV（时间无效）位置位时，时标后加 `时间无效` 标记（error）。
- 所有时间戳统一毫秒；秒级精度值显式补 `.000`，避免同列对不齐。

### 7.4 公共地址 / 源发地址

- CA 显示为 `CA=1`（等宽），永远带前缀，避免与 IOA 混淆。
- OA 仅在 `≠0` 时显示，格式 `OA=3`，次要色。

### 7.5 序号 N(S) / N(R)

- 显示 15 位数值原文（0–32767），不转换为十六进制。
- 序号异常（重复、跳号、回绕错误）→ 该帧加 `序号异常` 标签（error），并在日志留一条 WARNING。
- S 帧只显示 N(R)，I 帧显示 N(S)/N(R)。

### 7.6 类型标识

显示 `名称(ID)`，如 `单点信息(1)`。未知类型用 error 色 + 原始 ID，禁止只显示数字。
SQ=1 时在类型后加 `SQ` 标记；信息对象个数 >1 时显示 `×N`。

## 8. 命令安全

### 8.1 二次确认

必须二次确认：
- 遥控（YK）单/双点命令；
- 设点（YC）与升降（STEP）中的**跨量程/越限**值；
- 系统级操作：复位进程、删除点表/站点、清空历史。

可免确认（但必须回显结果）：
- 总召、对时、读、测试、启停模拟、导出。

确认弹窗必须包含：`目标点名`、`IOA`、`类型`、`方向/动作`、`当前值 → 目标值`、`是否 SBO`。
方向必须用业务词（`合闸` / `分闸`），不得用 `ON/OFF/1/0`。

### 8.2 SBO

- SBO 点位在选择成功后必须进入可见的"已选择未执行"状态，并提供**撤销（DEACT）**入口。
- 选择态必须有超时倒计时或提示（协议侧由对端超时，界面不能假装永久有效）。
- 目标 IOA / 类型变更时，旧选择态立即失效并提示。

### 8.3 危险色边界

| 操作 | 按钮类型 |
|---|---|
| 分闸、复位、删除、清空 | `danger` |
| 合闸、设点（在量程内）、升降 | `primary` |
| 选择（SBO select）、撤销选择 | `default` |
| 读、总召、对时、测试、导出 | `default` |

**当前实现问题**：`PointCommandDialog` 把所有命令的确认按钮一律设为 `danger`，导致"合闸"与"分闸"
同样红，危险色失去区分度（附录 A-4）。

### 8.4 不可执行状态

引擎未运行、未连接、点位未启用、参数非法时，按钮**保留可见但禁用**，并在同一区域给出原因文案
（禁止只禁用不解释）。`PointCommandDialog` 已按此实现，作为模板。

## 9. 趋势 / 日志 / 报文

### 9.1 趋势

- X 轴用时间轴（`type:'time'`），支持 5m / 15m / 1h / 6h 预设 + "跟随实时"开关。
- 序列 >2 条或点数 >5000 时启用降采样（现有 `sampling:'lttb'` 保留），并在角落标注"已降采样"。
- tooltip 必须含：点位名、`值 + 单位`、时标（毫秒）。
- 图例固定顶部、可点击隐藏；颜色只从 token 取，序列间色差需通过对比度检查。
- 空态必须给出下一步动作：「双击点表的值单元格加入趋势」。
- 暂停/断线时，曲线末端加 `数据中断` 标记，不画直线连接断点前后的值。

### 9.2 日志

- 列：时标 / 级别 / 来源 / 消息。级别与来源固定宽度，消息占剩余空间并允许换行省略。
- 级别过滤默认全选；暂停时显示"暂停期间新增 N 条"。
- 导出必须含毫秒时标、级别、来源，UTF-8 with BOM（Excel 直接打开不乱码）。
- 单条消息超过 200 字符时折叠，点击展开（避免一行撑爆）。

### 9.3 报文

- 列顺序固定：`时间 / 方向 / 格式 / 长度 / N(S) / N(R) / 类型 / COT / CA / IOA / HEX`。
- 悬停 HEX 分段显示协议逐段解释（已实现，翻译失败时显示原文而非"翻译失败"）。
- 自动滚动在用户滚动后暂停，并显示"已暂停跟随 · 点击恢复"。
- 复制按钮复制原始 HEX（大写、无空格），另提供"复制解码文本"。

## 10. 无障碍

1. **对比度**：见 §4.4，由 Playwright 门禁强制。
2. **焦点可见**：全局 2px 焦点环 + 2px 偏移（`global.css`），不得 `outline:none` 除非提供等效替代。
3. **键盘可达**：所有鼠标交互必须有键盘等价物——表格行 `Tab` 可达、`Enter` 选中、`Ctrl+Enter` 触发命令弹窗、`Esc` 关闭。
4. **焦点顺序**：与视觉顺序一致；打开 `Modal` 后焦点进入弹窗并在关闭后归还触发元素（antd 默认行为，勿破坏）。
5. **触控目标**：≥24×24 CSS px（WCAG 2.2 SC 2.5.8）。
6. **语义**：图标按钮必须有 `aria-label`；表格用原生 `<table>` 语义；`html lang` 随语言切换。
7. **动画**：尊重 `prefers-reduced-motion`，自动滚动/曲线动画在开启时停止。
